What the source changes do
------------------------------------------------------------------------------

Canvas / selection
  - updateScene accepts historyBaseline. Undo stores that snapshot, not the
    last live preview, so one undo rewinds a whole drag.
  - Board move-drag keeps an origin map. pointercancel restores origin
    without committing. Commit passes origin as historyBaseline.
  - SceneSelectionOverlay onChange(next, commit, previous). Scale, rotate,
    and bend pass the pre-gesture members as previous.
  - Keep-proportions dock toggle (aria-label "Keep proportions") plus Shift.
    Corner handles scale uniformly in resizeBounds.
  - Dock X is clamped so rotate/flip/delete stay on screen.
  - Selection menu buttons are 38px. Pressed lock state uses the hover fill.
  - New bend points get roundness type 3. paintScene quadratic-curves
    polylines that have roundness.
  - pointercancel on overlay restore does not commit.
  - getCommonBounds includes rotated AABB corners so exports do not clip.

Overlay perf
  - SceneOverlay skips JSON.stringify when viz element refs are unchanged.
  - Image cache keys off fileId + dataURL pairs instead of stringify.

Viz
  - layoutForest takes nodeHeight and places roots at the node centre, so
    trie / unionfind / calltree / segtree sit below the frame label.
  - calltree uses one width for every node (max label in the program).
  - union-find arrows point from member to parent (edge id edge-{to}-{from}).
  - Tests: roots below header; union-find pointer dy < 0.

Tooling
  - .gitignore and Vite watch ignore app/.tmp-viz-review/.
  - app/scripts/viz-review.{mjs,tsx,html} headless Chrome review of viz.
